# Bamboo Intelligence Pro

## Run
```powershell
npm install
npm run build
npm run dev
```
Demo: `analyst@bamboo.io` / `bamboo123`. User data persists in localStorage. Sound uses the Web Audio API and can be disabled in Settings.
